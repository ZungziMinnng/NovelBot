NovelBot 使用说明
==================================================

【怎么开始】

双击「启动NovelBot.bat」。

首次启动会自动下载运行所需的组件，大约 300-400MB，走的是国内镜像，
不需要梯子。这一步只发生一次，请耐心等几分钟，不要关窗口。
完成后浏览器会自动打开。

如果 Windows 弹出防火墙提示，点「允许」。程序只监听本机，不对外开放。


【第一次进去要做什么】

1. 用管理员账号登录。用户名是 admin，密码在首次启动时生成，
   显示在启动窗口里，也保存在 backend/data/初始密码.txt。
   登录后建议在设置里改掉。

2. 去「设置」页面添加 API 供应商，填入你自己的 API Key。
   支持 OpenAI 兼容接口（含各类中转站）、Google Gemini、Anthropic。
   程序本身不含任何 API Key，也不代付费用。

3. 添加模型。至少配一个对话模型；想用检索功能的话，
   再配一个嵌入模型（在模型库里把类型标为 embedding）。


【关于数据】

你写的所有内容都存在 backend/data 文件夹里，不上传到任何地方。
备份就是把这个文件夹复制走。换电脑时把它覆盖到新的程序目录即可。

删除程序时如果想保留作品，先把 backend/data 备份出来。


【怎么关闭】

关掉启动时那个黑色窗口就停止了。


【可选功能：本地重排】

双击「安装重排功能.bat」。这是给检索结果加一层精排，写长篇时找
参考资料更准一些。需要约 4.6GB 磁盘，建议有 NVIDIA 显卡再装。
不装也能正常用。


【出问题了】

首次启动下载失败：多半是网络问题，重新双击启动即可，
已经下载好的部分会保留，不会从头再来。

启动窗口一闪而过：看程序目录下的 install.log。

提示端口 8000 被占用：可能已经有一个 NovelBot 在运行，
先检查有没有另一个窗口，或者直接用浏览器打开 http://127.0.0.1:8000

生成时提示「还没有配置嵌入模型」：去小说设置里选一个嵌入模型，
或者在上下文设置里关掉需要检索的选项。
