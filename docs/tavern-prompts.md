# 酒馆提示词

进入「酒馆 → 酒馆设定 → 提示词」可查看和修改五类提示词：

| 提示词 | 使用时机 |
| --- | --- |
| 角色扮演 | 每轮单人或群聊的系统提示开头 |
| 剧情摘要 | 较早对话超出保留窗口，需要压缩为长期记忆时 |
| 帮我想想 | 生成四条候选玩家回复时 |
| 角色卡生成与优化 | 使用角色卡栏目旁的 AI 生成功能时 |
| 角色卡介绍 | 使用 AI 生成给作者看的简介时 |

自定义内容按账号保存在数据库，适用于该账号的所有酒馆角色卡和对话；管理员在这里修改的也是自己的配置。保存后从下一次调用生效，不会重写已有消息或摘要，进行中的调用继续使用其开始时的配置。

每项提供变量说明、默认内容预览和「恢复默认」。模板使用 Jinja2 的变量、条件与循环；保存时校验语法、变量名与示例渲染。保持摘要所需的对话变量，以及回复建议每行一条、共四行的格式，才能让功能正常工作。

角色扮演模板之后仍会拼入角色卡系统指令、人物设定、玩家资料、命中的世界书、剧情记忆和已勾选的写作规则。「常用指令」是填入角色卡的文本副本；「写作规则」由角色卡勾选；「提示词」则修改对应功能的基础模板。

恢复默认会删除当前账号对此项的覆盖，回到服务器当前的内置模板。管理员在全局设置中修改服务器模板，只会影响没有个人覆盖的账号。
